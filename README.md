# 💰 Who Wants to be a Millionaire?

**Who Wants to be a Millionaire 💰 ?** - an iOS 📱  unofficial adaptation of the 📺 TV Show WWTBAM, written in SwiftUI

---

## 📄 About the Project 

**Who Wants to be a Millionaire?** - a demonstrative app, showcasing the basics of what a quiz app should do

With this app, users can:  
- **❓ Answer interesting questions!**  
- **💵 Win prizes^ for answering!**  
- **🔵 Use Lifelines when needed!**  
- **💰 Cash Out or Stay to Win!**

^ This app was created purely for educational and demonstrational purposes. No economic exchanges will happen.
